# Imágenes de la propuesta

- `media/`: las 20 imágenes originales PNG/JPEG extraídas del PowerPoint, conservando sus nombres internos. Incluyen fotografías de piezas y productos, un esquema geométrico y recursos de la presentación.
- `slides/`: las 11 diapositivas completas exportadas con PowerPoint a PNG de 1600 × 900 píxeles. Incluyen las formas nativas usadas en el dibujo de montaje.

La correspondencia de imágenes con diapositivas se conserva en [presentation_index.json](../../references/presentation_index.json). El [resumen Markdown](../../presentation_summary.md) usa las vistas completas y enlaza las fotografías originales relevantes.

El PowerPoint no contiene medios SVG. El vector independiente `spiral_sensors.svg` y su PNG original están en [la carpeta de geometría](../../../hardware/mechanical/geometry/README.md).
