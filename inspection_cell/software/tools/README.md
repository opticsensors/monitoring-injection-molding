# Utilidades de desarrollo

Espacio para futuras herramientas de enumeración de cámaras, prueba de comunicaciones de báscula, captura manual, inspección de calibración y reproducción de imágenes guardadas.

Cada utilidad deberá indicar si requiere hardware y dónde escribe. Las pruebas de diagnóstico deben poder ejecutarse sin iniciar la adquisición DAQ. No hay todavía herramientas operativas de la celda en esta carpeta.

El único script aportado como referencia inicial es [spiral_sensors.py](../../hardware/mechanical/geometry/spiral_sensors.py), conservado junto a la geometría original.
