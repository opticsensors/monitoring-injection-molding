# Configuración prevista

Aquí se mantendrán ejemplos versionados y recetas cuando se conozcan equipos y magnitudes. No hay parámetros operativos aprobados.

Separar:

- Estación: identificador, cámara, báscula, puertos, almacenamiento y servicios.
- Cámara: exposición, ganancia, ROI, formato y referencia de calibración.
- Báscula: protocolo, unidad, umbral de presencia, banda de retirada y criterio de estabilidad.
- Receta: tipo de pieza, tratamiento de colada, región de medida, magnitudes y límites de producto cuando se definan.
- Calibración: identificador, fecha, configuración de montaje, patrón y archivos asociados.

Los umbrales y tiempos deben salir de ensayos. Los secretos y ajustes específicos de una instalación no se incluirán en ejemplos versionados. Evitar duplicar el esquema de configuración DAQ, que pertenece a otra aplicación.
