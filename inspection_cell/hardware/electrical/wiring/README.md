# Planos y registro de cableado

Espacio reservado para el esquema de alimentación y comunicaciones cuando se seleccionen los equipos.

Para cada cable registrar: identificador, origen/destino, referencia, longitud, conectores, señales/tensión, fuente de la asignación de pines y recorrido mecánico. Incluir interfaces entre PC, cámara, báscula y panel/controlador.

Por ahora solo existe una referencia comercial de cable USB de cámara, de 2 m, en la [oferta IN26-1893](../../components/quotes/README.md). No asumir que esa longitud cubre una columna de hasta 2 m más el trayecto al PC.
