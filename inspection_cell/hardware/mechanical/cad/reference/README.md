# CAD original de referencia

Origen: carpeta `quality control` indicada por el usuario. Se conservaron los nombres originales y se copiaron todos sus archivos `.SLDPRT`, `.SLDASM` y `.x_t` para mantener juntos los ficheros recibidos.

Incluyen la pieza espiral de revisión V2, un ensamblaje denominado `dim espiral`, una exportación del molde con sensores y selector, placas/selectores y componentes mecánicos asociados. La relación exacta entre revisiones y las dependencias del ensamblaje quedan por validar en la herramienta CAD.

El inventario preciso, los tamaños y las huellas de integridad están en el [manifiesto de fuentes](../../../../docs/references/source_manifest.json). No se han extraído cotas de estos ficheros ni se ha comprobado que el conjunto sea autocontenido. La geometría documentada numéricamente procede del script Python suministrado.
