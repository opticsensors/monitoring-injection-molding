# Informes de ensayo

Todavía no existen informes de validación de la celda. Este directorio recibirá resultados reales, no conclusiones anticipadas.

Cada informe debe indicar fecha, protocolo y revisión, responsable, equipos, calibración, software, muestras, condiciones térmicas/mecánicas, datos y ubicación de imágenes, resultados, incertidumbres/limitaciones y conclusión frente al criterio acordado.

Usar nombres con fecha y tema, por ejemplo `AAAA-MM-DD_altura_y_longitud.md`. Conservar aquí evidencias seleccionadas y enlazar el almacenamiento de series voluminosas. Cerrar decisiones en [docs/decisions.md](../../docs/decisions.md) solo cuando exista evidencia suficiente.
